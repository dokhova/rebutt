# [название] — трекер кишечника

Мобильное веб-приложение: дневник стула по Бристольской шкале, самочувствие, цикл, разбор еды по фото через ИИ, инсайты и показатель «работа кишечника».

**Стек:** Vite (vanilla JS, свой мини-рантайм на morphdom) · Vercel (статика + серверные функции `/api`) · OpenAI · Supabase (данные + анонимная авторизация) · PostHog (аналитика).

```
index.html                 оболочка
src/
  main.js                  точка входа
  runtime.js               шаблонизатор {{…}}, <sc-if>, <sc-for> + morphdom
  config.js                название, версия документов, ссылка на поддержку, env
  components/App.js        вся логика экранов + события аналитики
  templates/app.html       разметка экранов (онбординг, Сегодня, +, Инсайты, Профиль)
  services/
    analytics.js           PostHog + дубль событий в Supabase
    supabase.js            клиент, анонимный вход
    store.js               профиль/записи: localStorage + Supabase
    ai.js                  запросы к /api
    files.js               сжатие фото, CSV, отчёт для врача
api/                       серверные функции Vercel (ключ OpenAI только здесь)
  food.js                  фото блюда → название, ккал, клетчатка, оценка, совет
  ask.js                   вопрос пользователя → ответ по его записям
  insights.js              совет на сегодня + «ИИ заметил»
  _lib/openai.js           вызов OpenAI, проверка JWT Supabase, rate limit
public/legal/              соглашение, политика, согласие на данные о здоровье
supabase/migrations/       SQL-схема с RLS
docs/ANALYTICS.md          словарь событий и что собрать в PostHog
```

## Запуск за 15 минут

### 1. Supabase
1. Создать проект на supabase.com.
2. **Authentication → Sign In / Providers → Allow anonymous sign-ins: ON.** Без этого данные не сохранятся.
3. **SQL Editor** → вставить `supabase/migrations/20261018000000_init.sql` → Run.
4. **Project Settings → API**: скопировать `Project URL` и `anon public` key.

### 2. PostHog
**Project settings** → скопировать Project API key (`phc_…`) и посмотреть регион (EU / US).

### 3. GitHub
```bash
git init && git add . && git commit -m "init"
git branch -M main
git remote add origin https://github.com/<you>/<repo>.git
git push -u origin main
```

### 4. Vercel
1. **Add New → Project → Import** репозиторий. Framework определится как Vite.
2. **Environment Variables** — всё из `.env.example`:
   - `OPENAI_API_KEY` — ключ OpenAI (без `VITE_`, чтобы не попал в браузер)
   - `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`
   - `VITE_POSTHOG_KEY`, `VITE_POSTHOG_HOST`
3. Deploy. После изменения переменных — Redeploy.

### Локально
```bash
npm i
cp .env.example .env.local   # заполнить
npx vercel dev               # фронт + /api на http://localhost:3000
# или только фронт: npm run dev (ИИ работать не будет без vercel dev)
```

## Режимы
- **Обычный** — реальные даты, данные пользователя, ИИ через `/api`.
- **Демо** — `/?demo` (или `/?demo#home`, `#add`, `#insights`, `#profile`): тестовые данные 20–26 сентября, ответы-заглушки, ничего не сохраняется. Для показов и юзер-тестов.
- Без Supabase приложение работает только на устройстве (localStorage). Без PostHog — без аналитики. Без OpenAI — с ошибкой на ИИ-функциях, остальное работает.

## Где что менять
- Название приложения — `src/config.js` (`APP_NAME`) и `[название]` в `public/legal/*.html`.
- Ссылка поддержки — `SUPPORT_URL` в `src/config.js` (сейчас `https://t.me/the_dokhova`).
- Документы — `public/legal/*.html`. Заполнить плейсхолдеры `[…]` (ФИО/компания, страна, email). При правке текста поднять `LEGAL_VERSION` в `src/config.js`.
- Промпты ИИ — `api/*.js`, общие правила безопасности — `SAFETY` в `api/_lib/openai.js`.
- Модель — переменная `OPENAI_MODEL` (по умолчанию `gpt-5-mini`).

## Данные
| Таблица | Что |
|---|---|
| `profiles` | профиль из онбординга и настройки |
| `consents` | журнал согласий: документ, версия, время, user agent |
| `gut_entries` | стул (had/none), тип 1–7, симптомы |
| `meals` | разобранные ИИ блюда (фото не храним) |
| `period_days` | отмеченные дни месячных |
| `analytics_events` | дубль всех событий PostHog |

Все таблицы под RLS: пользователь видит только свои строки. «Удалить все данные» в профиле удаляет всё по пользователю и сбрасывает аналитику.

## Юридическое — что важно знать
- **Оферта отдельно не нужна, пока приложение бесплатное.** Пользовательское соглашение уже оформлено как публичная оферта на бесплатное использование. Когда появится оплата — понадобится отдельная оферта на платные услуги (цена, порядок оплаты, возвраты).
- Документы — шаблон, а не юридическая консультация. Перед запуском заполнить реквизиты и показать юристу.
- Если основная аудитория — граждане РФ, по 152-ФЗ первичная запись их персональных данных должна идти в базу на территории РФ, а оператор — уведомить Роскомнадзор. Supabase/PostHog/OpenAI за рубежом — это нужно решить до масштабирования.
- Минимальный возраст в приложении — 18 лет (так проще с данными о здоровье).

## Что не сделано (следующие шаги)
- Напоминания утром/вечером сохраняются в профиль, но push/Telegram-рассылки ещё нет.
- Учётная запись анонимная и привязана к браузеру. Для переноса между устройствами — вход через Telegram или email (Supabase Auth умеет связать анонимный аккаунт).
- Rate limit в `/api` — в памяти инстанса; при росте нагрузки заменить на Upstash/Redis.
